# Choose the documentation index

This path remains as a repository link for older records. It is not the hosted
Sphinx source root.

- To learn RAES, complete the [quickstart](public/quickstart.md).
- To explore research questions, read the [research context](public/research.md).
- To cite RAES, use the [citation guide](public/citation.md).
- To find all reader pages, read the [public documentation](public/index.md).
- To find architecture, research, migration, audit, release, and workflow
  records, use the [developer documentation index](README.md).

Only files under `docs/public/` enter the hosted build, search index, sitemap,
and pull-request preview.
