# Governance records

Use the [issue-bound scope reference](requirement-scopes/README.md) to interpret delivery manifests.
The numeric JSON filenames identify the issue that uses each manifest.
Only the matching issue branch activates its scope.
These records are workflow reference, not public product contracts.

Requirement statements and status remain in the [requirement reference](../requirements/README.md).
The [scope reference](requirement-scopes/README.md) names the exact fields, validation rules, and authority paths.
Keep historical manifest identities and assignments intact.
Use the [development workflow](../DEVELOPMENT_WORKFLOW.md) for current contribution steps.
